# Sasirangan Banua

Website katalog UMKM kain Sasirangan khas Banjarmasin.

## Demo Langsung

https://username.github.io/nama-repository/

## Fitur

- Katalog produk kain Sasirangan.
- Data produk diambil dari file JSON menggunakan Fetch API.
- Pencarian produk.
- Filter berdasarkan kategori.
- Halaman informasi tentang Sasirangan Banua.
- Formulir pemesanan.
- Widget jadwal salat Banjarmasin dari API MyQuran.

## Teknologi

- HTML5
- CSS3
- JavaScript
- JSON
- Fetch API
- Git dan GitHub

## Struktur Proyek

- index.html : Halaman utama.
- kontak.html : Halaman formulir pemesanan.
- css/style.css : Pengaturan tampilan website.
- js/katalog.js : Pengelolaan katalog produk.
- js/jadwal-salat.js : Pengambilan data jadwal salat.
- data/katalog.json : Penyimpanan data produk.
- img/ : Penyimpanan gambar dan favicon.

## Cara Menjalankan

1. Download atau clone repository.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Jalankan index.html menggunakan Live Server.

## Sumber Data

- Data produk: data/katalog.json.
- Jadwal salat: API MyQuran.
- Gambar: aset gambar yang digunakan dalam proyek.
